MIRHAN HUSSEIN — ANIMATED BIRTHDAY INVITATION

Files are placed directly in this ZIP (no enclosing folder), ready to upload to the root of a GitHub repository and publish with GitHub Pages.

HOW TO PUBLISH
1. Create or open a GitHub repository.
2. Upload all files in this ZIP to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch, select the main branch and /(root), then Save.
5. Open the published Pages URL after deployment finishes.

INTERACTIONS
- Open Invitation switches from animated page 1 to animated page 2.
- Instagram, Facebook, and Wikipedia hotspots open their linked pages in a new tab.
- The birthday comment button opens a pop-up form; visitors can add a name and message.

IMPORTANT ABOUT COMMENTS
GitHub Pages is static hosting, so this ZIP's comments are stored only in the visitor's own browser and are not shared with other visitors. Public/shared comments require connecting a comments backend/provider (for example, Giscus configured for your public GitHub repository). The site does not claim to publish comments globally.
